# Desert dialogue

Original Chinese scripts in `src/data/desert-dialogue.json`, rendered offline with eSpeak NG and normalized/encoded using FFmpeg. These are synthetic prototype voices, not recordings or imitations of any real person. Twelve local MP3 files, mono 24 kHz / 48 kbps; no remote TTS or paid service used at runtime.

The app uses subtitles and explicit playback/replay. Sound clarity and preferred voices remain subject to family UAT. Regenerate with `scripts/generate-desert-voices.py` (eSpeak NG + FFmpeg needed only for authoring).
