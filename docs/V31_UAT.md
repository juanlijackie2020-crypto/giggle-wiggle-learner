先在测试分支部署的 HTTPS 地址试玩。PR 可以先保持打开，不必合并到正式站点才做 UAT。当前分支为 `feat/forest-amber-level-one`；已有 main 部署不会因为本分支提交自动更新。

## 获得独立试玩链接（Netlify）

如果现有 Netlify 站点跟随 main，它暂时不会显示本分支的升级。可创建一个独立测试站点，保留当前正式站点：

1. Netlify → Add new project → Import an existing project → GitHub，选择 `juanlijackie2020-crypto/giggle-wiggle-learner`。
2. 部署分支选择 `feat/forest-amber-level-one`，Build command 填 `npm run build`，Publish directory 填 `dist`。
3. 部署完成后，打开 Netlify 给出的 `https://…netlify.app` 链接。用这个链接在电脑和 iPhone Safari 中试玩；不要打开下载的 HTML 附件预览。
4. UAT 发现的问题记录在下方模板；满意后才合并 PR，让正式 main 站点更新。

手动创建 PR：打开仓库 → Pull requests → New pull request；base 选 `main`，compare 选 `feat/forest-amber-level-one`。把 [PR 说明](PULL_REQUEST.md) 的内容填入描述，点击 Create pull request。创建 PR 是整理代码变更和审核入口，不等于立即合并或发布。

## A：先试玩视觉与装扮（约 10 分钟）

1. 打开游戏，点击“创建角色，开始冒险”。拖动预览人物，检查是否真的能从不同角度看到方块角色。
2. 依次试雨衣、兔耳连帽装、工匠背带装，观察帽子/耳朵/背带轮廓差异。
3. 试 8 个衣色与 6 套成套配色；保存进入森林，再刷新，检查外观一致。
4. 对照六关全景图，观察森林绿、金色琥珀、花草、木牌按钮与暖色面板。由骞骞判断是否更想探索；由家长检查文字是否好读。
5. 手机横屏/竖屏各试一次，打开并滚动装扮面板，确认能找到保存和关闭按钮。

通过标准：造型与颜色真实变化、可保存、触控操作可用、家长与孩子认可视觉方向。精细场景丰富度仍可在试玩后调整。

## B：动物对话与声音

1. 出生点靠近兔子，按 E / 手机互动。应听到主角问候，然后动物回答，字幕标出说话者。
2. 选择“询问线索”，应先听到主角的问题，再听到动物的线索。试“重播当前句”“跳过这句”。
3. 在对话中静音，应立即停声；恢复声音后主动点重播，不突然播放旧对白。
4. 关闭对话、切换后台，再回来，不能有过期语音继续播放。暂停菜单分别调整对白和音效音量。
5. 与六种动物各互动一次；检查线索可理解、音量舒适、字幕匹配。断网/音频失败时仍能通过字幕继续任务。

当前 15 段中文音频为离线合成的原型配音，非真人录音；声音自然度、中文清晰度和儿童喜好必须试听验收。若不合适，可替换同名 MP3 为已授权的人声，不用重写玩法。

## C：随机计算题

1. 收集 3 木头、5 琥珀，到北面的宝箱开始答题，每题 4 选项，共 3 题。
2. 答错两次，确认先出现文字提示，再出现与当前算式对应的琥珀点阵。
3. 关闭题目或刷新，确认算式、选项顺序、提示与已答对进度保持。
4. 暂停 → 家长视图 → 确认家长入口。选择 10 / 20 / 50 以内难度；本轮保持原题，重新开始下一轮才生效。
5. 再开一轮，确认与上一轮没有相同题干。加法交换操作数也算重复题。
6. 通关后再重玩，木头方块奖励始终为 10，不因新题组重复发奖。

升级自 V3.0 的进行中存档会先保留旧固定题组；明确重新开始后切换到随机题。旧奖励和学习记录保留。

## D：三类可选任务

- **森林好朋友**：任务板选中任务。出生点找兔子、小路左侧找松鼠，在对话中选择一次回应。两步完成后获得“森林知己”徽章。
- **森林发现家**：任务板选中任务，寻找蓝色旗。桥边南岸、过桥后的左侧树屋入口、北方琥珀林各互动一次，获得徽章。
- **木桩小勇士**：出生点右后方的三块渐高木桩，先走到靠南的起点。按顺序跳上木桩，再与北端终点旗互动。途中落地可重试；主线物品和永久奖励不丢失。

试切换任务、刷新、确认放弃；任务面板应明确显示哪几步已完成。可选任务不影响主线宝箱条件，徽章不可重复领取。
