# 骞骞的学习方块世界｜3D冒险游戏 PRD V3.0

版本日期：2026-11-01

状态：六关视觉方向已由骞骞确认；工程规格待开发验证

视觉基准：a_vibrant_minecraft_style_game_infographic_poster.png（2026-11-01 最新六关全景图）

产品类型：原创体素风格、第三人称3D网页冒险游戏（不是Minecraft模组，也不是小程序）

目标用户：约6岁儿童；家长为题库与进度管理者。

## 1. 产品目标与设计原则

让孩子先因为探索、收集、跑酷、解谜而想玩，再通过数学（主要）和少量语文题获得游戏奖励。完整循环：角色换装 → 进入地图 → 探索/任务/躲避怪物 → 解题 → 开宝箱 → 获得材料 → 建造/解锁下一关。

- 游戏优先：题目嵌入机关、宝箱，不把整张地图变成练习册。
- 学习有效：题目可重试，提供逐级提示；记录独立答对和提示后答对，不以惩罚促学习。
- 适龄安全：怪物为卡通风格，无血腥；失败回到检查点，不能永久失去奖励。
- 真实3D：角色和摄像机可移动、场景可探索、地形有碰撞；概念插画不能代替可玩的3D原型。
- 美术原创：采用原创体素角色、纹理、名称和场景；不得直接复制Minecraft官方素材。

## 2. 用户与核心体验

玩家：骞骞。辅助用户：家长。玩家首次进入角色装扮室，自定义方块小人的肤色、衣服颜色、服装款式；自动存档，关卡内一致显示。第三人称镜头；电脑支持WASD、空格、E、鼠标旋转；手机支持屏幕方向键、跳跃、互动与触控镜头。大字体中文UI、背包、任务追踪、检查点、音量开关。

失败与重试：跌落、碰到怪物或触发陷阱只重置当前挑战段；不清空已经领取的永久奖励。支持随时暂停与重新开始关卡。

## 3. 六大关卡（最新全景图版）

### 关卡1｜森林琥珀保卫战

- 地图：大型森林、树屋、河流、独木桥、琥珀树林、怪物区、宝箱区。
- 动物：大量小兔子、长尾鹿、松鼠、小鸟、狐狸、刺猬等；可观察、互动或获取线索。
- 怪物：超级多僵尸、骷髅、苦力怕，按区域/波次刷新；数量视觉上密集，实际同屏数量由性能限制控制。怪物碰撞使玩家返回附近检查点；可通过躲避、绕路和安全区完成，不强制战斗。
- 任务：收集3块木头与5块琥珀，经过森林障碍，找到宝箱。
- 学习：10以内加减法3题（初始题：3+4=7；9−5=4；6+2=8）。
- 奖励：木头方块×10；琥珀为本关收集品，可在背包展示（是否跨关使用待确认）。
- 验收：动物可见且可互动；木头/琥珀计数正确；大量怪物出现但不卡死；题目正确后才发奖励。

### 关卡2｜沙漠神殿大迷宫

- 地图：大型多岔路迷宫、绿洲、沙丘、骆驼、沙漠动物、神殿大厅、宝物密室。
- 任务：在迷宫中找到3块神殿石板，破解机关，进入神殿，发现宝藏；骆驼可以骑乘或互动（第一版可先实现互动，骑乘为扩展）。
- 学习：两位数加减法3题（23+14=37；46−12=34；35+20=55）。
- 奖励：黄金钥匙×1；神殿宝物作为可展示收集品。
- 验收：迷宫存在分岔、死路、提示和至少一个检查点；不能仅用一条直路代替迷宫。

### 关卡3｜天空方块岛：3秒消失彩虹桥

- 地图：云海、浮空岛、彩虹方块桥、远处宝箱岛。
- 任务：在有限时间内跨越方块桥；踩上每块指定方块3秒后消失，跳离后倒计时继续。第1秒开始闪烁，第2秒红色警告，第3秒移除碰撞和画面。
- 失败：掉进云海后回到当前挑战段起点；该段所有临时方块恢复并重置计时。
- 学习：图形与规律3题（三角形有3条边；正方形有4个角；○△○△○后接△）。
- 奖励：彩虹方块×8。
- 验收：精确3秒消失、离开不暂停、掉落重置、触屏可跳跃；假方块机关暂不加入（尚未获确认）。

### 关卡4｜海底遗迹

- 地图：海洋、珊瑚、海底神殿、遗迹走廊、藏宝室。
- 动物：海豚、海龟、章鱼、热带鱼等。
- 任务：探索海底遗迹，寻找3块海洋钥匙/线索，破解机关；提供儿童友好的氧气/安全机制（第一版可不设窒息惩罚）。
- 学习：数学计算与图形识别，默认3题；具体题库待单独审定。
- 奖励：海洋宝石（数量待定）。
- 验收：可水下移动，至少3种海洋动物，遗迹有探索目标和宝箱。

### 关卡5｜火山熔岩之地

- 地图：熔岩河、移动石台、火山洞窟、机关门、火山宝箱。
- 任务：跨越移动平台、躲避熔岩怪和陷阱，收集3块火焰水晶。
- 学习：加减法和简单应用题3题；具体题库待单独审定。
- 奖励：火焰水晶/火山宝石（永久奖励数量待定）。
- 验收：移动平台可实际站立；触碰熔岩回检查点；没有真实伤害表现。

### 关卡6｜龙之城堡：终极挑战

- 地图：大型龙之城堡、火焰机关、冰霜机关、旋风机关、龙之长廊、最终宝箱。
- 敌人规则（骞骞最新确认）：要骷髅，不要僵尸。本关城堡守卫以大量骷髅和骷髅弓箭手为主；不要加入僵尸。是否保留苦力怕待确认，默认不加入，避免偏离最新要求。
- 任务：穿过火焰/冰霜/旋风三大机关，收集3枚龙之印记，躲避骷髅守卫，打开终极宝箱。巨龙可作为场景守护者或非血腥Boss机制。
- 学习：综合数学与图形题3题；推荐沿用最初已确认题库（18+7=25；30−13=17；4组每组5颗=20），全景概念图里的高难题仅作视觉示意，不直接作为6岁儿童必答题。
- 奖励：钻石王冠×1、通关庆祝动画；额外宝石数量待定。
- 验收：只有骷髅类守卫，没有僵尸；三大机关都可交互；完成题目后发放王冠并展示通关。

> **版本冲突处理**：本版以用户最新确认的六关全景图为准，因此第2关是沙漠神殿，第4关是海底遗迹，第5关是火山；不再把旧版“水晶矿洞、魔法文字村”误认为当前六关。旧版“三元宝箱·水晶矿洞”可作为后续支线，尚不属于这六关的正式范围。

## 4. 游戏系统需求

| 模块      | MVP要求                                 | 验收要点                        |
| --------- | --------------------------------------- | ------------------------------- |
| 3D世界    | 6张原创体素地图，固定场景，碰撞与检查点 | 能走、跳、转镜头、触发交互      |
| 角色装扮  | 肤色、衣服颜色、款式；存档              | 退出重开仍保留                  |
| 任务追踪  | 地图目标、进度、下一步提示              | 不会卡在无法完成的状态          |
| 怪物AI    | 巡逻、追逐、返回原位；性能限流          | 无血腥，玩家可通过绕路/重试通关 |
| 动物互动  | 观察、对话提示、简单互动                | 动物与怪物行为有明显区分        |
| 数学题    | 题库JSON、自动判分、提示、重试          | 答案不提前显示给孩子            |
| 奖励/背包 | 唯一奖励ID、数量、领取状态              | 不重复刷奖励，重开不丢失        |
| 自动存档  | 本地存档；记录关卡、装扮、背包          | 刷新后可继续                    |
| 家长视图  | 参考答案、正确率、提示次数              | 不与儿童答题界面混用            |
| 触屏适配  | 虚拟摇杆/方向键、跳跃、互动             | 手机浏览器内可玩                |

### 数学学习规则

- 每关3题为首版默认；数学为主，少量语文可由家长后续配置。
- 首次错误给出简短提示，第二次可展示图形化思路；允许无限重试，不公开羞辱或惩罚。
- 记录 attemptCount、hintCount、firstTryCorrect、completedAt，区分独立掌握和提示后完成。
- 第4、5关题目尚未最终确认，开发前必须补全并审题；不得将概念图里偶然生成的题目视为准确题库。

## 5. 技术架构与数据结构

推荐：React + TypeScript + Vite + Three.js / React Three Fiber + Rapier；JSON配置地图、题库、任务和奖励；localStorage初版存档，未来可迁移到云端。通过 HTTPS 部署，避免 iPhone 文件预览黑屏问题。采用场景分区加载、实例化渲染、怪物同屏数量限制、移动端降级画质。

核心实体：PlayerAppearance、LevelDefinition、Objective、Checkpoint、MobSpawn、Question、Reward、SaveGame。

示例配置：

```json
{
  "levelId": 3,
  "name": "天空方块岛",
  "mechanics": {
    "disappearingPlatforms": {
      "delayMs": 3000,
      "countdownContinuesAfterExit": true,
      "resetOnCheckpointRespawn": true
    }
  },
  "reward": { "itemId": "rainbow_block", "quantity": 8 }
}
```

## 6. 开发优先级与里程碑

M0｜技术验证：可通过 HTTPS 在 iPhone Safari 和桌面 Chrome 打开；展示真实3D森林，移动、跳跃、触屏操作均可用。先解决此前黑屏问题。

M1｜第1关垂直切片：森林场景、可换装人物、动物、琥珀、3木头、怪物、3道数学题、宝箱、背包、存档完整闭环。怪物规模采用可调参数，先保证稳定帧率。

M2｜机制样板：第3关3秒消失方块；第2关大型迷宫。验证最有特色的跑酷和解谜机制。

M3｜六关完整内容：加入海底、火山、龙堡；完整题库、奖励和通关动画。

M4｜学习与创作扩展：自由建造、错题复习、家长学习报告、动态题目难度。非首发阻断项。

## 7. 测试与发布验收

1. 手机Safari通过 HTTPS 正常加载3D场景，不出现只有HUD和深色背景的黑屏。
2. 电脑和手机都能移动、跳跃、转镜头、与任务物品互动。
3. 六关均有起点、目标、检查点、失败重试和最终奖励。
4. 第1关有大量森林动物、琥珀、僵尸/骷髅/苦力怕；密集场景仍能稳定游玩。
5. 第2关是真正有分岔和探索路径的大迷宫，并有骆驼与宝物。
6. 第3关踩上方块3秒后消失；离开不停止倒计时；掉落后重置本段。
7. 第6关有骷髅守卫，没有僵尸。
8. 答错可以重试，提示生效，答案准确，奖励不能重复领取。
9. 刷新/退出重开后装扮、背包和通关进度保持。
10. 游戏素材为原创，提供音效静音与暂停入口。

## 8. 待确认事项（不阻塞M0/M1）

- 第4、5关具体3道题及最终奖励数量。
- 第6关是否完全不加入苦力怕（当前默认不加入）。
- 森林琥珀是否可用于跨关兑换，还是仅作收集品。
- 骆驼骑乘是否必须进入首发版（当前建议先互动、后骑乘）。
- 游戏中是否允许非血腥攻击怪物，还是只采用躲避/机关防御（首版建议躲避优先）。
