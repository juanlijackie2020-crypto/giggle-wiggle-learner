## 已知限制与未验证

1. **配音是离线合成的原型声音，非真人录音。** 自动化可确认音频加载与播放进度、字幕及静音行为；中文清晰度、声音自然度、孩子喜好仍须家长试听。建议按 [UAT 清单](V31_UAT.md) 决定是否换为专业配音。
2. **真实 iPhone Safari HTTPS 未验证**；Chromium 移动视口/触摸模拟不能替代真机 Safari。Safari 播放限制下提供主动重播/重试入口。
3. **真实手机长期帧率、发热和 30 FPS 目标未验证**。场景继续采用实例化、合并静态几何、24 怪物上限和触屏 DPR 1；低画质可关闭阴影。物理引擎保持 1/60 固定步长，每个渲染帧最多推进两个子步，低帧率时优先减慢游戏而不让角色瞬间跨过落点。
4. 森林仍是原创程序体素素材，视觉丰富度和 UI 吸引力需家长与骞骞对照附件验收。未复制 Minecraft 素材；未实现攻击系统。
5. 构建包含 Three.js 与 Rapier WASM，仍有大分包提示，首次打开慢网需要等待；资源随站点发布，不从外部 CDN 载入。
6. 存档仅在同一浏览器；清除网站数据会丢失进度。家长入口是防误触，不是密码验证。
7. 本次提交到开发分支不等于线上已更新。请用分支 HTTPS 预览进行 UAT，通过后再合并并部署。
