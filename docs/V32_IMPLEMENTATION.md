# 第一关 V3.2 · 森林扩展与装备

日期：2026-11-06。只开发第一关。本次参考用户提供的角色/动物/绿色怪物/河畔森林图片，以原创程序体素几何重新制作模型；未导入图片中的官方素材。

## 实现

- 可走地图 80 × 84（原 44 × 52，面积约 2.94 倍），地面与物理边界同步扩大；主线位置不变。增加花甸、白桦林、第二座有栏杆的桥、可进入小屋、可跳上的低山台阶、花草石径和远景山峰。
- 树叶深浅绿像素斑块、明亮草地/沙色河岸/蓝色河流。绿色四足怪改为亮绿、深绿、黄绿原创像素斑块；怪物仍固定最多 24 个。
- 人物增加面部、分层头发、服装缝线、鞋底；六种动物分别有不同身体比例与物种细节。动态肢体分开合并，静态细节合并，树和怪物细节实例化。
- 可装备、收起和挥动的青晶镐；近距离采琥珀和四处石英。按 F 或屏幕挥镐按钮，也支持 E / 点击矿物。未装备时提示，不发放矿物；不增加攻击系统。
- 所有衣服都可显示实体背包（肩带、盖袋、扣带、侧袋）。12 格物品背包、数量、详情、装备状态、可旋转人物预览；B / 屏幕按钮打开。
- 基础镐/背包默认免费提供；旧存档自动补齐；背包外观隐藏不丢物品。矿点唯一 ID 去重，石英、永久木头奖励、徽章跨重玩保留；主线材料仍按原规则每轮重置。

## 先做这一轮的 UAT

部署分支预览方法见 [部署与模块 UAT](V31_UAT.md)。通过 HTTPS 打开网站，不用 HTML 文件预览。

1. **人物 / 动物 / 颜色**：打开装扮或背包，旋转人物检查眼睛、头发、衣服、工具和背包。到出生点找兔子、到路边看狐狸/松鼠，观察不同轮廓。对照参考图验收绿色四足怪，记录孩子认为仍需修改的细节。
2. **工具 / 背包**：打开背包，选镐 → 收起；靠近琥珀挥镐，应提示装备。重新装备后可采集。选背包 → 收起，人物背包隐藏但数量保留。刷新再检查设置。
3. **扩展地图**：出生点向后（南）走到花甸，再向东（右）寻找矿点。用镐采石英后沿东侧石径向北，通过第二座桥，到小屋门口并进入。原中央木桥仍可用。
4. **永久收藏**：背包显示石英 ×1；刷新或重新开始关卡后仍保留，已经采过的矿点不恢复。奖励木头方块不重复发放。
5. **手机**：横竖屏分别试摇杆、跳跃、挥镐、背包、装备切换及关闭面板；确保手指能准确点到按钮。

验收记录：HTTPS 地址、提交号、设备/系统/浏览器、操作、期望/实际、截图、通过/待改/未验证。

## 已知边界

- 原创体素低多边形模型已细化，但参考图的精细光影与内容密度不是自动通过的美术验收；需要家长与骞骞试玩确认。
- 真实 iPhone Safari HTTPS、长期手机帧率、发热和耗电 **未验证**。
- 远山是背景，扩展区仍有物理边界；不支持自由挖地、游泳、战斗、物品丢弃或建筑放置。镐用于已配置的琥珀和石英采集点。
- 石英只有四处，属于收藏展示；没有兑换或消耗经济。背包容量足够本关全部物品，不增加满包丢失惩罚。
- 既有语音仍为合成原型；本轮不重新录制配音。
- 开发分支提交不会自动更新跟随 main 的正式站点。
