## 本关决策

- 琥珀只作为本关收集物在背包展示，不在未确认时增加跨关兑换。
- 怪物只触发安全点回退，无攻击、爆炸伤害或血腥表现。
- 提示后作答次数计入正确率分母；首次是否独立答对单独保存。首次完成时间保存 ISO 时间，家长视图按设备本地时间显示。
- 历史存档没有的学习记录显示“未记录”，不假定孩子以前独立答对。重玩累计学习记录，但本轮提示级别归零。
- 本轮完成标记与永久通关标记分开，避免“重新开始”丢失永久奖励 / 通关记录。

## 仍未验证

2026-11-04 已收到六关全景图附件，并将视觉方向写入 PRD V3.1；游戏尚未按新方向改造或完成视觉 UAT。iPhone Safari 真机、线上 HTTPS、长期手机帧率仍待实测。家长入口不是身份认证；题库为本地 JSON，M1 不包含家长在线编辑器、云存档或 M4 学习报告扩展。
