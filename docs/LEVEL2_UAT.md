# 第二关 · 沙漠神殿大迷宫 · 家庭 UAT

版本：V3.3 第二关原型，2026-11-11。第一关已通过用户 UAT；本表仅验收第二关与跨关体验。

## 如何进入

[点击第二关试玩入口](https://deploy-preview-1--wordwood.netlify.app/?level=2)。也可打开部署地址，在末尾加 `?level=2`，或在游戏顶部点“关卡”。第一关已经通关可直接选第二关；否则点“家长 UAT：直接体验第二关”→“我是家长，进入第二关测试”。这个入口不改变第一关通关状态或奖励。

测试新关时请保留原浏览器和站点域名，避免误以为不同域名共享存档。不要清除网站数据。手机用 HTTPS 页面，不用 HTML 附件预览。

## 骞骞的反馈

- 最喜欢哪个地方或动物？
- 有没有看不清、不知道怎么走、难以控制的地方？
- 计算题太简单、刚刚好，还是太难？
- 哪句声音听不清？希望谁再陪你走一会儿？
