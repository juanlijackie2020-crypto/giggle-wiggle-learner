第一关「森林琥珀保卫战」按 PRD V3.1 升级为可反复探索的 3D 冒险。原来每次只有固定的三道题、三种服装和文字动物线索；现在每轮生成不同计算题，可选择三类支线任务、六款服饰，并听到主角和动物的中文对话。保留 3 木头 + 5 琥珀 → 解题 → 宝箱 → 一次性木头 ×10 的闭环，不实现其余五关。

- 随机题采用 JSON 难度/提示规则，默认 20 以内，家长可选 10 / 20 / 50；包含加减和进位，相邻题组去重，刷新保持题目/选项/提示状态。
- 三类可选任务使用实际场景互动：兔子与松鼠对话、探索旗帜、跳跃木桩；任务切换保留进度，完成后一次性徽章入包。
- 8 种衣色、6 种服饰、6 套配色和可旋转 3D 预览；明亮森林、木牌/纸张 UI、移动端触控与低画质设置。
- 15 段本地中文 MP3，主角与六类动物都有台词；字幕、重播、回应选择、音量、静音、播放失败重试及后台取消，不依赖后端或系统 TTS。
- 存档迁移保留旧角色、固定题进度、学习记录与永久奖励；新题组使用独立轮次 ID，旧奖励不随随机题重开重复发放。

验证命令：`npm run build`、`npm test`、`PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:e2e`。生产构建及 24 项单元测试通过；16 个浏览器场景均有通过记录（完整回归先通过 14 项，其余两项修复后与怪物碰撞共 3 项定向复测通过）。执行结果、截图及设备限制见 [V3.1 实现与验证](docs/V31_IMPLEMENTATION.md)。可先按 [分模块 UAT](docs/V31_UAT.md) 验收视觉与装扮，不需等其余关卡。

限制：配音为离线合成原型，需家长与孩子试听确认音色；附件风格的主观视觉验收、真实 iPhone Safari HTTPS、长期手机帧率/发热未验证。已有 GitHub Pages 工作流保留，合并 main 后经测试部署；开发分支提交不代表正式站点已更新。
