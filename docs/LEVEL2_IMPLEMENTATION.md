- 固定 JSON 迷宫图：49 个连通区域，51 条通道，8 个真实岔路口，4 个死路，3 个独立回环。三块石板位于不同终端支路。地图只显示已探索区域。
- Rapier 地面/墙/门/砂岩碰撞、第三人称移动与跳跃、相机遮挡检测、物品互动遮挡检测。普通墙不可挖；月亮石板支路的松砂岩必须装备镐清理。
- 原创骆驼、耳廓狐、蜥蜴模型；12 段本地普通话 MP3（约 0.74 MB），主角问候/请求、伙伴回答、动态选择下一块未拿石板的线索。骆驼沿迷宫图走短程，并在玩家落后时等待；MVP 不骑乘。
- 4 个石头守卫只在外围沙丘活动；巡逻、近距离追逐、回原区；碰到玩家返回当前已激活安全旗。主通道/对话/宝箱安全，无战斗或口渴。
- 三块石板 → E 放入机关开门 → 3 道随机计算 → 实际箱盖动画 → 黄金钥匙 ×1 的主线闭环。
- 热身 20 / 标准 50 / 挑战 100 以内；每组一加一减一随机；标准/挑战使用两位操作数且至少一道进位题。相邻题组按语义排除重复。4 个唯一合法选项；错误重试、两级提示、家长记录；本轮题组固定保存。
- 三类独立可选支线：骆驼/耳廓狐交友，绿洲/日晷/壁画发现，按顺序跟三组脚印返回中庭；一次性徽章。两处永久石英矿点。
- 第一关外观和工具共享；免费沙漠护目镜/围巾可开关，有真实模型；实体镐和背包继续可见。背包每页 12 格、分类、分页，包含真实跨关物品。
- schema 3 兼容旧 schema 1/2；保留第一关平面字段以减少迁移风险，第二关单独保存在 `desert` 中。重新开始任意一关不清除另一关进度。黄金钥匙通过 `level-2:gold-key:v1` 唯一领取；状态和奖励在同一 JSON 写入，动画前提交。
- 多标签页侦测外部更新后暂停旧页并要求重新载入，写入前合并永久奖励/矿点/徽章集合。单机 localStorage，不跨设备同步。
- 关卡选择与明确家长 UAT 入口；正常入口需第一关已通关，UAT 入口不伪造第一关通关或奖励。

## 稳定性与实际限制

- 地图静态块合并顶点颜色几何；动物按关节合批，守卫固定 4 个，无无限生成。移动端 DPR 1、桌面最高 1.5；手机/省电画质关闭实时阴影。两张地图不会同时加载在一个场景中。
- 地图可玩区 96 × 96，迷宫墙覆盖约 42 × 42；外圈供地标、动物、矿石和守卫探索，面积不冒充迷宫面积。
- 双向语音使用离线合成的原型音色，真实中文清晰度和骞骞的喜好待家庭 UAT。没有麦克风或自由语音识别。
- 骆驼只带一小段路；不会替玩家完成整条路线，也不能穿过未清理的砂岩。重新进入场景时回到营地，再次互动可继续给当前线索。
- 检查点保存，不保存每一帧坐标。刷新回到当前安全旗，本轮石板和题目保留。手动安全返回优先已发现中庭，否则当前安全点，不传送到锁门后的宝箱。
- iPhone Safari HTTPS 真机、低端 Android 帧率/发热、真实扬声器音质：**未验证**。Chromium 手机视口模拟不等于真机 Safari。
- 主线首轮 10–20 分钟是设计目标，实际儿童游玩时长待家庭反馈。
- 本地进度支持恢复和去重，不防用户主动修改开发者工具，也不是多设备云存档。
